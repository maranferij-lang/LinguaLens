**Твоя частина** — реєстрації, ключі, кабінети: покроково в
[`USER_TODO.md`](USER_TODO.md) (Apple Developer → підписки → RevenueCat →

відповіді App Privacy і нотатки для рецензента — у [`APPSTORE.md`](APPSTORE.md).

**У коді:** нічого блокуючого. Ліміт сканів тепер довічний, тож дата з
`x-local-date` на нього взагалі не впливає (тести в `server/test/`).

**Перевірити на справжньому iPhone** (у симуляторі й на вебі цього не видно):

| Що | Чому під питанням |
|---|---|
| Наліпка лягає рівно по предмету | на реальних кадрах із `gemini`, різні форми й відстані; найважливіше для вірусності |
| Пресети зуму 1× / 2× | зум у `expo-camera` відносний (0–1), і реальне збільшення залежить від моделі iPhone |
| Якість PNG карток | `react-native-view-shot` на справжньому екрані: різкість тексту, контур наліпки (SVG clip-path), розмір файлу |
| Instagram зі системного меню | чи відкривається Stories, а не лише стрічка, і як виглядає 9:16 |
| Хаптика | у симуляторі її немає взагалі |
| Час сповіщень | слово дня о вибраній годині щодня; нагадування за 2 дні до кінця тріалу; тап після холодного старту |
| Keychain після перевстановлення | ліміт сканів не обнуляється, Pro не губиться |
| Sandbox-покупка і Restore | скан після безкоштовного проходить після покупки; Restore на іншому телефоні переносить Pro |
| Швидкість скану | 1.5–2 с від затвора до картки на мобільному інтернеті |

## 3. Продуктовий план

### v1.1 — утримання й ріст
1. **Sign in with Apple + синхронізація словника** (iCloud або наш сервер).
   Зараз новий телефон = порожній словник. Акаунт з'явиться тоді, коли дає
   людині цінність (бекап, кілька пристроїв), а не як формальність.
2. **Віджет зі словом дня** на головному екрані й екрані блокування. Щоденне
   нагадування без пушу; сильний аргумент і для App Store Featuring.
3. **Instagram Stories напряму**: наліпка поверх історії, а не просто картинка.
   Потрібен Facebook App ID (див. `USER_TODO.md`, «Необов'язково»).
4. **Sentry** — звіти про падіння. Зараз `ErrorBoundary` пише лише в консоль.

### v1.2 — глибина
5. **Кілька предметів з одного кадру**: один скан = 3–5 слів. Сильний Pro-аргумент.
6. **App Attest / DeviceCheck**, коли витрати на AI почнуть рости швидше за
   кількість людей (див. `SECURITY.md`).
7. **SQLite (`expo-sqlite`) для словника.** Зараз увесь словник — один JSON в
   AsyncStorage, який перезаписується цілком. До ~1000 слів це нормально,
   для синхронізації й великих колекцій — ні.
8. **Більше мов інтерфейсу**: зараз en / uk / de / es, решта мов телефону
   отримує англійську. Далі — fr, it, pt, pl.

### Далі
- Розмовна практика зі збережених слів.
- Автогрупування слів за темами (їжа, одяг, дім).
- Спільні набори слів — поділитися колекцією з другом.

## 4. Технічний борг

- **`App.js` (~830 рядків) тримає весь стан.** Наступна велика фіча
  (синхронізація) — привід винести стан у стор (Zustand або Context + reducer),
  а вкладки — на `expo-router`. Тоді й пуш зможе відкривати конкретну картку слова.
- **TypeScript.** Почати з чистої логіки: `srs.js`, `subscription.js`,
  `stickerGeometry.js`, `server/billing.js`.
- **PNG маскота по ~230 КБ** кожен — зменшити до реального розміру показу.
- **Ліміти частоти в пам'яті** одного інстансу Cloud Run — при кількох
  інстансах перенести у Firestore або Memorystore.
