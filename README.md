# LinguaLens 📷 → 🌍

Апка для iPhone: наводиш камеру на предмет — отримуєш його назву мовою, яку вчиш, з транскрипцією, перекладом, прикладом і озвучкою. Слова йдуть у словник, звідти — у флешкартки з інтервальним повторенням і квіз.

Архітектура: **апка → твій сервер → AI API**. Ключі живуть тільки на сервері, користувач нічого не налаштовує.

## 1. Запуск сервера (обов'язково)

```powershell
cd server
copy .env.example .env
```

Відкрий `.env` у блокноті та заповни:

- **Для тестів (безкоштовно):** `PROVIDER=gemini` і `GEMINI_API_KEY=...` — ключ береться за 1 хв на [aistudio.google.com/apikey](https://aistudio.google.com/apikey), картка не потрібна.
- **Для якості (платно):** `PROVIDER=anthropic` і `ANTHROPIC_API_KEY=...` з [console.anthropic.com](https://console.anthropic.com/settings/keys).
- **`AUTH_SECRET`** — обов'язково для акаунтів. Згенерувати:
  ```powershell
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  ```

Потім:

```powershell
npm start
```

Сервер напише свою адресу, напр. `http://192.168.0.102:3000`. Перевірка: `http://localhost:3000/health` → `{"ok":true,"provider":"gemini","store":"file"}`.

Локально юзери зберігаються у `server/data.json`. У хмарі — у Firestore (див. `DEPLOY.md`).

## 2. Адреса сервера в апці

У `src/api.js`:

```js
export const SERVER_URL = 'http://192.168.0.102:3000';
export const APP_TOKEN = ''; // порожньо локально
```

Телефон і комп'ютер мають бути в одній Wi-Fi мережі.

## Дизайн-система

Макети: [Figma](https://www.figma.com/design/c5DX8UXHJUdO58fwjIRTFq) — 11 екранів
у світлій темі, 3 у темній, токени й компоненти на сторінці Foundations.
Код і макет тримають ті самі значення; звірка — у `figma/STATE.md`.

**Тепла крейда + один акцент.** Тло ніколи не чисто-біле (`#FAF8F4`). Акцент
`#5B4FD6` узятий піпеткою зі шкіри маскота Lingo і поглиблений до контрасту
5.6:1 на цьому тлі. Це єдиний насичений колір інтерфейсу: бірюза з його
черевця працює тільки на станах успіху, бурштин — тільки на серії днів,
червоний — тільки на помилці. Тіні теплі (`#5C4F3D`), не сірі: сіра тінь на
теплому тлі виглядає брудно.

Замість галереї з восьми тем — одна фірмова у світлому й темному варіанті
плюс «Авто». Старі ключі тем мігрують автоматично (`resolveThemeKey`).


Рух і типографіка зібрані за двома опублікованими наборами правил:
[emilkowalski/skills](https://github.com/emilkowalski/skills) (design engineering, `apple-design`)
і [Nutlope/hallmark](https://github.com/Nutlope/hallmark).

`src/motion.js` — єдине джерело правди для анімацій:

| | |
|---|---|
| **Криві** | посилені безьє: `out (0.23,1,0.32,1)`, `inOut`, `drawer` з iOS. `ease-in` на UI не використовується ніде — він гальмує саме тоді, коли око найуважніше |
| **Тривалості** | натиск 120 · підказка 190 · панель 240 · аркуш 280 · **вихід 170** — вихід завжди швидший за вхід |
| **Пружини** | задаються як в Apple — парою `(response, damping)`, а не масою/жорсткістю. За замовчуванням `damping 1.0` — **без перельоту**: елемент, який просто з'явився, ніхто не кидав. Переліт (`0.82`) лишився тільки на перевороті картки |
| **Стагер** | 40–45 мс між сусідніми елементами, обрізка на шостому |
| **Продуктивність** | усі 10 анімацій ідуть через `useNativeDriver` на GPU. Прогрес-бари масштабуються по X замість зміни `width` |
| **Reduced motion** | системне «менше руху» прибирає зсуви, покачування маскота і тремтіння форми — лишає непрозорість і хаптику |

`src/theme.js` — трекінг і інтерліньяж залежать від кегля (правило Apple: одне
значення на всі розміри завжди десь хибне): 34 pt → −0.75, 17 pt → −0.10,
дрібні кепси → +1.1. Функція `type(size, family)` віддає готовий стиль.

`src/Chrome.js` — таб-бар як напівпрозорий матеріал з `expo-blur`; контент
проїжджає під ним, замість жорсткого роздільника — світлий край.

Скануй QR камерою iPhone → відкриється в Expo Go.
Не підключається? `npx expo start --tunnel` (обходить VPN і фаєрвол).

> Несумісний SDK в Expo Go? `npx expo install expo@^<номер з Expo Go>` + `npx expo install --fix`.

## 5. Наступні кроки до релізу

1. `DEPLOY.md` — задеплоїти сервер у Google Cloud Run + увімкнути Firestore.
2. `eas build` + `eas submit` — публікація в App Store без Mac (Apple Developer $99/рік).
3. Політика приватності (обов'язкова для App Store, бо є акаунти) і тексти сторінки застосунку.

## Як працює «слово дня»

1. Кожен юзер при реєстрації отримує випадковий `seed`.
2. Сервер перемішує список із 320 слів детерміновано під цей seed → у кожного свій порядок.
3. Слово на день N = `порядок[(індекс_дня + N) % 320]` — тому повторів немає ~11 місяців.
4. Апка тягне 7 днів наперед, кешує локально і планує 7 локальних сповіщень на вибрану годину.
5. Переклади кешуються на сервері — один і той самий переклад не запитується в AI двічі.
