# Як тестувати LinguaLens на Mac

Встановлення інструментів описане в [`SETUP_MAC.md`](SETUP_MAC.md). Тут про те,
**де** що перевіряти, і чеклист на 15 хвилин.

---

## Де що перевіряти

| | Симулятор iPhone | iPhone + Expo Go | iPhone + development build |
|---|---|---|---|
| Як запустити | `npm run start:go` → `i` | `npm run start:go` → QR камерою | `npx expo run:ios --device` |
| Камера, скан, наліпка | ❌ камери немає | ✅ | ✅ |
| Словник, колекція, картки, квіз, профіль | ✅ | ✅ | ✅ |
| Картки «поділитися» і системне меню | ✅ (Instagram там немає, «Зберегти зображення» є) | ✅ | ✅ |
| Пейвол і покупки | імітація | імітація | справжні (sandbox), якщо в `.env` є ключ RevenueCat |
| Сповіщення | ✅ | ✅ | ✅ |
| Вхід через Apple, синхронізація | ⚠️ лише якщо симулятор увійшов в Apple Account (Параметри → Увійти) | ⚠️ сервер має приймати `host.exp.Exponent`: `APPLE_AUDIENCES=com.marik.lingualens,host.exp.Exponent` у `server/.env` | ✅ |
| Хаптика | ❌ | ✅ | ✅ |
| Матове скло таб-бара, сплеш, іконка | — | ❌ показує своє | ✅ |

Найшвидше так: увесь UI проганяєш у симуляторі, а камеру й наліпки на iPhone.
Перед релізом ще раз усе в TestFlight (див. [`APPSTORE.md`](APPSTORE.md)).

> Expo Go з App Store підтримує лише найновіший SDK (у нас 57). Якщо Expo Go
> пише «Project is incompatible», онови Expo Go або збери development build.

## Сервер без ключів (PROVIDER=mock)

```bash
cd ~/Documents/LinguaLens/server
cp .env.example .env        # один раз
npm run dev
```

`mock` відповідає без мережі й без ключа: завжди «кружка» (`mug` / `die Tasse` /
`la taza`) з рамкою по центру кадру. Слово дня приходить як англійське слово
з заглушкою замість перекладу. Цього вистачає, щоб пройти весь застосунок від
камери до флешкарток.

Справжнє розпізнавання: у `server/.env` впиши `PROVIDER=gemini` і
`GEMINI_API_KEY=…` ([безкоштовний ключ](https://aistudio.google.com/apikey)),
потім `npm start`. Чи **рівно лягає наліпка на предмет**, перевіряй саме так:
у mock рамка завжди по центру, хоч би що було в кадрі.

Корисне в `server/.env` для тестів:

| Змінна | Навіщо |
|---|---|
| `FREE_SCANS_PER_DAY=2` | швидше впертися в ліміт і побачити пейвол |
| `FREE_SCANS_PER_DAY=1000` | сканувати без обмежень (імітована покупка серверний ліміт не знімає, див. нижче) |

Після зміни `.env` перезапусти сервер (`Ctrl+C` → `npm run dev`). Почати з
чистого аркуша найпростіше із самого застосунку: Параметри → Дані →
«Стерти всі мої дані».

У застосунку **Параметри → внизу** видно адресу сервера й позначку `auto`
(знайшовся сам) або `env` (взято з `.env`). Кнопка «Перевірити з'єднання»
пінгує `/health`.

## Чеклист на 15 хвилин

Порядок не випадковий: кожен пункт спирається на попередні.

### Перше враження (симулятор)
- [ ] Онбординг: три екрани, кнопка «Почати» внизу, під великим пальцем
- [ ] Ніякого входу чи реєстрації: одразу камера
- [ ] Мова інтерфейсу збігається з мовою телефону (uk/en/de/es, інші → англійська)

### Скан і наліпка (iPhone)
- [ ] Перший тап по затвору (навіть якщо онбординг пропущено) відкриває «Перед першим сканом»: текст про сервер і AI-сервіс, посилання на політику, «Дозволити» / «Не зараз». «Не зараз» — нічого не надсилається, наступний тап питає знову. Після «Дозволити» більше не питає
- [ ] Наведи на предмет і натисни затвор. Відповідь за 1.5–2 с; якщо 20+ с, щось не так з мережею
- [ ] Подвійний тап по затвору не робить двох сканів
- [ ] Наліпка вирізана **по контуру предмета**, з білою облямівкою й тінню, з'являється з легким «попом»
- [ ] Контур лежить рівно на предметі й не з'їхав убік (тільки з `gemini`)
- [ ] «Прослухати» звучить навіть із вимкненим звуком на боковому перемикачі
- [ ] «Зберегти» → слово є в Словнику
- [ ] **Закрий застосунок повністю** (свайп у перемикачі) і відкрий знову: наліпка на місці

### Сцена: уся кімната одним кадром (iPhone)
- [ ] Над затвором — «ПРЕДМЕТ · СЦЕНА», обраний жовтий і стоїть по центру. Тап або свайп по видошукачу перемикає, з легким «клацом». Після перезапуску режим той самий
- [ ] У режимі «Сцена» видошукач — високий кадр 9:16, підказка про кімнату чи стіл
- [ ] Затвор: кадр застигає (прев'ю плавно стискається до фото 9:16 на чорному), легке затемнення й відблиск, рядки статусу міняються. Результат за 5–12 с
- [ ] Поява: контури прокреслюються, решта фото пригасає, предмети піднімаються наліпками (біла облямівка, тінь), підписи вискакують по черзі. З увімкненим «Зменшення руху» — просто проявляється
- [ ] Підписи не налазять один на одного, не ховаються під верхню й нижню панелі; відсунутий підпис має тонку лінію з крапкою на предметі
- [ ] Контури лежать рівно на предметах (тільки з `gemini`/`anthropic`; mock дає 4 умовні предмети)
- [ ] Тап по підпису або предмету → картка: озвучка, транскрипція, приклад, «Зберегти». «Показувати на картці» вимкнено → підпис блідне, предмет більше не піднятий, число в заголовку меншає
- [ ] «Зберегти всі (N)» → слова в словнику, кожне з наліпкою, вирізаною з цього кадру
- [ ] Безкоштовна стеля: при 98 словах «Зберегти всі (5)» → 2 збережено, сцена закривається, видно пейвол; після покупки решта зберігається сама
- [ ] «Поділитися» → 3 вигляди (Наліпки, Підписи, Рамка) × 4 палітри; приховані підписи відсутні; «Зберегти зображення» → 1080×1920
- [ ] Словник → стрічка «Сцени»: тап відкриває сцену, довгий натиск — видалити (з підтвердженням). Після перезапуску й після оновлення збірки з TestFlight фото сцен на місці
- [ ] «Очистити словник» попереджає про сцени й прибирає їх; «Стерти всі мої дані» — теж
- [ ] Перша сцена → досягнення «Перша сцена» з'являється, щойно сцену закрито
- [ ] Десять сцен поспіль на найстаршому доступному iPhone — без вильоту (повний кадр звільняється після вирізання наліпок)

### Словник і картка слова
- [ ] Перемикач **Список | Колекція**. Колекція — альбом наліпок по 3 в ряд
- [ ] Тап по слову відкриває картку: наліпка, переклад, приклад, озвучка
- [ ] Картку можна змахнути вниз; якщо не дотягнути, вона пружинить назад
- [ ] Пошук фільтрує за словом і перекладом

### Поділитися
- [ ] З картки результату скану: «Поділитися» → аркуш з прев'ю
- [ ] Перегорни **всі 3 вигляди** слова і **всі 4 палітри** (фіолет, крейда, графіт, захід). Перевір довге слово (`die Geschirrspülmaschine`): текст не обрізається і не вилазить за край
- [ ] Кнопка відкриває **системне меню**: «Зберегти зображення» → у Фото картинка 1080×1920, чітка, без розмитих країв
- [ ] Те саме з картки слова в словнику
- [ ] Досягнення: відскануй/збережи перше слово → вгорі тост → **тап по тосту** → картка досягнення
- [ ] Профіль → відкрите досягнення → «Поділитися»
- [ ] Профіль → «Поділитися тижнем» → графік тижня і цифри збігаються з профілем
- [ ] Чесне питання до кожної картки: виклав би ти її в Stories? Якщо ні — запиши, що не так

### Навчання
- [ ] Флешкартки: картка перевертається, «Знаю» / «Ще вчу» переходять далі
- [ ] **Хрестик** закриває сесію посеред картки
- [ ] Коли нічого не на часі, запускається **режим тренування** з позначкою; після нього розклад повторень не з'їхав (на хабі той самий час наступного повторення)
- [ ] Квіз: 10 питань, таймер, завжди 4 **різні** варіанти; хрестик закриває
- [ ] Свідомо помились у квізі → це слово з'являється в повтореннях
- [ ] Ідеальний квіз або 10-те слово → системне вікно «Оцінити» (у dev-збірці може не з'явитись, це нормально)

### Ліміти й Pro (iPhone, mock-сервер — скани миттєві)
- [ ] **Серверний ліміт.** Постав у `server/.env` `FREE_SCANS_PER_DAY=2` і перезапусти сервер. Сьогодні вже було 2+ скани, тож наступний дає пейвол «На сьогодні скани закінчились»: сервер відповів 402 і AI не викликав. Поверни `5` і перезапусти сервер
- [ ] Скануй далі: коли лишилось ≤3, над камерою з'являється лічильник
- [ ] Після 5-го скану тап по затвору одразу відкриває пейвол, **без зйомки**
- [ ] У пейволі є хрестик, «Відновити покупки», Terms і Privacy (Privacy відкриває `<сервер>/privacy`). Пробний тиждень показано лише на річному плані
- [ ] Імітована покупка: Pro вмикається, зникають ліміти словника (100 слів) і мов (1 мова)
- [ ] Наступний скан однаково дасть пейвол: сервер про імітовану покупку не знає, і **так і задумано**. Справжнє зняття ліміту сервером перевіряється тільки зі sandbox-покупкою в dev build або TestFlight
- [ ] Параметри → «Відновити покупки» → «відновлено» або «нічого не знайдено»
- [ ] Параметри → «Керувати підпискою» відкриває системний аркуш (dev build з RevenueCat) або сторінку підписок Apple

### Дані
- [ ] Параметри → Дані → «Стерти всі мої дані» → підтвердити: словник порожній, наліпок немає, профіль з нуля
- [ ] Вимкни сервер і спробуй ще раз: застосунок чесно каже, що не вдалося, і **нічого не стирає**

### Акаунт і синхронізація (два iPhone з одним Apple ID, development build)
Сервер має бачити інтернет: токен Apple перевіряється ключами з appleid.apple.com.
- [ ] Без входу: Параметри → найперша картка «Акаунт»: що дає вхід одним реченням і офіційна кнопка **Sign in with Apple** на всю ширину — чорна у світлій темі, біла в темній
- [ ] Словник із 10+ словами без входу: над списком тиха підказка «У словнику вже N слів…». Тап відкриває Параметри; хрестик ховає її **назавжди** (після перезапуску не з'являється)
- [ ] iPhone A: «Sign in with Apple» → системне вікно **не питає ні імені, ні пошти** → картка «Вхід через Apple виконано · Синхронізовано щойно»
- [ ] Закрий вікно Apple, не входячи: жодної помилки, кнопка на місці
- [ ] iPhone B: збережи кілька своїх слів, серед них те саме, що вже є на A (`la taza`). Увійди тим самим Apple ID → слова з A з'явились, свої лишились, **`la taza` одна** і з наліпкою; тости досягнень не сиплються один за одним
- [ ] Збережи слово на A → на B воно з'являється, коли повертаєшся в застосунок або тиснеш «Синхронізувати зараз»
- [ ] Видали слово на B → після синхронізації воно зникає на A і **не повертається**
- [ ] Відповідай на картки на A в авіарежимі → у картці акаунта «Не синхронізовано: немає інтернету». Вимкни авіарежим, згорни й відкрий застосунок → «Синхронізовано щойно», прогрес повторень є на B
- [ ] Pro: оформи sandbox-підписку на B **до** входу → увійди (B переходить в акаунт A) → Pro лишився на B і з'явився на A
- [ ] «Вийти» на A → підтвердження (у Pro текст згадує, що Pro лишається в акаунті) → словник, прогрес і досягнення зникли, мова й тема на місці. Увійди знову → усе повернулося
- [ ] Зміни слово в авіарежимі й спробуй вийти → друге питання «Не все синхронізовано» → «Однаково вийти» виходить
- [ ] Видали застосунок на A (в акаунті) і постав знову → вхід і слова повертаються самі, без жодних дій
- [ ] «Стерти всі мої дані» на A в акаунті → акаунт і словник на сервері стерто; B при наступній синхронізації стає гостем зі своїми словами

### Сповіщення
- [ ] Параметри → «Слово дня»: увімкни і в «О котрій нагадувати» постав найближчу годину
- [ ] Згорни застосунок і дочекайся пуша зі словом (можна паралельно з іншими пунктами)
- [ ] **Тап по пушу** відкриває вкладку «Навчання» з карткою слова дня

### Камера без дозволу (iPhone)
- [ ] Параметри iOS → Expo Go (або LinguaLens) → Камера → вимкнути
- [ ] Вкладка сканера пояснює, що сталося; кнопка «Відкрити Параметри» веде прямо в налаштування застосунку
- [ ] Увімкни камеру назад → повернись → камера працює

### Тема і мови
- [ ] Параметри → Тема → **Темна**: увесь застосунок теплий графіт, а не синій; картки «поділитися» не змінились (у них свої палітри)
- [ ] **Авто** йде за системною темою (Параметри iOS → Екран і яскравість)
- [ ] «Моя мова» → English / Deutsch / Español / Українська: інтерфейс перекладений повністю, без англійських вкраплень і обрізаних рядків
- [ ] Мова навчання → іспанська → скан → слово іспанською з артиклем (`la taza`)

## Якщо щось пішло не так

| Симптом | Причина | Що робити |
|---|---|---|
| Скан: «Немає інтернету.», хоча інтернет є | застосунок не достукався до сервера: той не запущений або телефон в іншій Wi-Fi | перевір вікно сервера; Mac і iPhone в одній мережі; Параметри → адреса сервера → «Перевірити з'єднання» |
| iPhone не бачить сервер, хоча Wi-Fi та сама | iOS заблокував «Локальну мережу» для Expo Go | Параметри iOS → Expo Go → **Локальна мережа** → увімкнути |
| macOS питає, чи дозволити `node` вхідні з'єднання | файрвол Mac | **Дозволити**. Якщо відмовив: Системні параметри → Мережа → Файрвол → Параметри → `node` → дозволити |
| `EADDRINUSE: address already in use :::3000` | сервер уже запущений в іншому вікні | `lsof -i :3000` → `kill <PID>` |
| `--tunnel` працює, а скан ні | через тунель локальний сервер недосяжний | або без тунелю в спільній Wi-Fi, або хмарний сервер у `EXPO_PUBLIC_SERVER_URL` (див. `DEPLOY.md`) |
| `i` у Metro: «No development build installed» | `npm start` чекає на development build | `npm run start:go` (Expo Go) або спершу `npx expo run:ios` |
| `No iOS devices available in Simulator.app` | не обраний Xcode або немає симулятора | `sudo xcode-select -s /Applications/Xcode.app`; Xcode → Settings → Components → iOS |
| `npx expo run:ios` падає на `pod install` | CocoaPods або застаріла папка `ios/` | `brew install cocoapods`, потім `npx expo prebuild --clean --platform ios` і знову `npx expo run:ios` |
| «Project is incompatible with this version of Expo Go» | Expo Go старий або новий за SDK 57 | онови Expo Go з App Store; якщо не допомогло — `npx expo run:ios --device` |
| Змінив `.env`, а застосунок бачить старе значення | `EXPO_PUBLIC_*` вшиваються в бандл | `npx expo start -c` (з очищенням кешу) |
| Пейвол одразу після першого скану | денний ліміт на цьому пристрої вже вичерпано | постав більше `FREE_SCANS_PER_DAY` і перезапусти сервер або «Стерти всі мої дані» |
| Кнопка покупки: «покупки недоступні» | релізна збірка без `EXPO_PUBLIC_REVENUECAT_IOS_KEY` | задай ключ (див. `USER_TODO.md`, крок 7) і перезбери |
| Наліпка з'їхала з предмета | модель дала неточний контур | спробуй ще раз з іншого ракурсу; якщо повторюється — скріншот і слово мені |
| Немає звуку вимови | мова не встановлена в системі | Параметри iOS → Універсальний доступ → Усний контент → Голоси |
| Пуш не приходить | немає дозволу або година вже минула | Параметри iOS → LinguaLens (Expo Go) → Сповіщення |
| У Параметрах немає картки «Акаунт» | вхід через Apple тут недоступний (веб, Android, стара iOS) | так і задумано; перевіряй на iPhone |
| Вхід: «Apple не підтвердив вхід» | сервер не прийняв токен: найчастіше aud не той (Expo Go дає `host.exp.Exponent`) | додай його в `APPLE_AUDIENCES` у `server/.env` і перезапусти сервер; у лозі сервера видно причину |
| Вхід: «Вхід через Apple зараз не відповідає» | сервер не дістався до appleid.apple.com | перевір інтернет на Mac, де працює сервер |
| Вхід: «Не вдалося увійти» в симуляторі | симулятор не увійшов в Apple Account | Параметри симулятора → Увійти, або перевіряй на iPhone |
| `node -v` менше за 22.13 | старий Node | `brew install node@22 && brew link --overwrite node@22` |
